ติว TOEIC ฟรี — เว็บแยก (ไม่ต้องใช้ Claude)
=============================================

ไฟล์ในโฟลเดอร์นี้
  index.html          หน้าเว็บ (รวมภาพ Part 1 ไว้ในไฟล์แล้ว)
  data-listening.js   คลังข้อสอบ Listening
  data-reading.js     คลังข้อสอบ Reading Part 7
  config.json         สวิตช์เปิด-ปิดเว็บ

วิธีเปิด-ปิดเว็บ
  แก้ไฟล์ config.json แล้วอัปโหลดขึ้นโฮสต์ใหม่

  เปิดเว็บ:
    { "open": true, "message": "" }

  ปิดเว็บ พร้อมข้อความแจ้งผู้ใช้:
    { "open": false, "message": "เปิดอีกครั้งวันเสาร์ 9:00 น." }

วิธีนำขึ้นออนไลน์ฟรี (เลือกอย่างใดอย่างหนึ่ง)
  1) GitHub Pages — แนะนำ เพราะแก้ config.json ผ่านหน้าเว็บ GitHub ได้เลย
     - สมัคร github.com แล้วสร้าง repository ใหม่แบบ Public
     - อัปโหลดไฟล์ทั้ง 4 ไฟล์ (ไม่ต้องอัปโหลด README นี้ก็ได้)
     - ไปที่ Settings > Pages เลือก Branch: main แล้วกด Save
     - รอสักครู่ จะได้ลิงก์เว็บ
     - เวลาจะเปิด-ปิด: กดเปิดไฟล์ config.json บน GitHub กดรูปดินสอ แก้ true/false แล้วกด Commit

  2) Netlify — ลากโฟลเดอร์นี้ไปวางที่ app.netlify.com/drop
     - เวลาจะเปิด-ปิด ต้องแก้ config.json ในเครื่อง แล้วอัปโหลดโฟลเดอร์ใหม่

ข้อควรรู้
  - ต้องเปิดผ่านโฮสต์ (ลิงก์ https) การดับเบิลคลิก index.html ในเครื่องจะใช้งานได้
    แต่ระบบเปิด-ปิดจะไม่ทำงาน (ถือว่าเปิดเสมอ)
  - เสียง Listening ใช้เสียงอ่านของเบราว์เซอร์ผู้ใช้เอง คุณภาพและสำเนียงต่างกันไปตามเครื่อง
  - คะแนนเก็บในเบราว์เซอร์ของผู้ใช้แต่ละคน ผู้ดูแลมองไม่เห็นคะแนนของคนอื่น
  - การปิดเว็บเป็นการซ่อนหน้าจอ ไม่ใช่การล็อกข้อมูล คนที่รู้เทคนิคยังเปิดดูไฟล์ข้อสอบได้
  - โจทย์ทั้งหมดแต่งขึ้นใหม่ตามแนวข้อสอบ TOEIC ไม่ใช่ข้อสอบจริงของ ETS
